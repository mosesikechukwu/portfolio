# Serene Homes

A responsive estate agency website concept built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to preview it; no build step is needed.

## Photography

Architectural and interior photographs are served from Unsplash. The Unsplash license permits free use, including commercial use, subject to its terms: https://unsplash.com/license. Image URLs use the Unsplash image CDN and need an internet connection.

## Before launch

Replace the concept property details, contact information, testimonial copy, and journal entries with verified company content. Connect the enquiry link to a real inbox or contact form.
