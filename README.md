## Run locally

Open either project's `index.html` in a browser. Both are static sites with no build step. They use externally hosted images and fonts, so an internet connection is needed for those assets.

These are portfolio concepts. Replace sample listings, contact details, and checkout behavior with verified business information before using either site commercially.
